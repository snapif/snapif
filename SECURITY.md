# Security

Report a vulnerability in Snapif through [GitHub Security Advisories](https://github.com/snapif/snapif/security/advisories/new). Do not open a public issue for an unfixed vulnerability.

## Supported versions

Fixes land on the 0.2 line. The 0.1 line does not receive them.

| Version | Supported |
| --- | --- |
| 0.2.x | yes |
| 0.1.x | no |

## What to include

- The Snapif version or git SHA
- The command or library call
- What you expected and what happened
